## SCHEMA EMITIDO

`Organization` + `LocalBusiness` · `WebSite` · `BreadcrumbList` · `FAQPage` ·
`Person` · `BlogPosting`

`Product` **não** é emitido na v1 — sem preço e sem oferta o markup fica frágil e
gera aviso no Search Console. `FAQPage` só aparece onde a pergunta e a resposta
estão visíveis na página.

`LocalBusiness` é emitido **sem `streetAddress`**, com `addressLocality`,
`addressRegion` e `areaServed`. É a configuração correta para uma
*service-area business* — a Tower não tem loja física desde 2018.

## CORREÇÕES APLICADAS DURANTE O QA

**1. Contraste abaixo do mínimo AA**
`--color-ink-3` estava em `#767b85`, que dá **4,14:1** sobre o papel — reprovado
para texto pequeno (mínimo 4,5:1). Escurecido para `#6e737c` → **4,63:1**.
No rodapé escuro, `text-paper/45` (4,35:1) e `text-paper/40` (3,67:1) foram
elevados para `/55` e `/60`.

**2. Quatorze saltos de hierarquia de heading (h1 → h3)**
Os títulos de seção eram `<p class="eyebrow">`, o que deixava o primeiro heading
depois do H1 ser um H3 — problema real para leitor de tela. Convertidos para `<h2>`
mantendo a aparência de rótulo.

**3. Oito `title` acima do limite de exibição**
Reescritos para caber com o sufixo da marca dentro de ~60 caracteres.

**4. Célula vazia na grade**
Com 7 itens em 3 colunas, a linha incompleta exibia a cor da régua como um bloco
cinza solto. Corrigido com preenchimento calculado.

**5. `group-hover` aplicado no próprio elemento `.group`**
Em "Continue lendo", o hover nunca disparava. Substituído por `hover:` direto.

**6. Link de WhatsApp sem contexto no rodapé**
Era o único dos 30 que não carregava mensagem. Agora carrega — nenhum CTA genérico
sobrevive no site.

**7. Alvos de toque de 39px**
Os chips de navegação ficavam pouco abaixo do confortável no celular.
Elevados para ~44px.

## PERFORMANCE

- **102 kB** de JS compartilhado; páginas entre 105 e 112 kB no *first load*.
- Todas as rotas pré-renderizadas como HTML estático.
- JavaScript de cliente apenas onde há interação real: menu do celular,
  formulário de orçamento, ferramenta de orientação e rastreamento de clique.
- Zero biblioteca de terceiros no navegador. Sem framework de animação, sem UI kit.
- Fontes auto-hospedadas via `next/font`, com `display: swap` e subset latino.
- `prefers-reduced-motion` respeitado globalmente.

**Não medido ainda:** Core Web Vitals de campo. Só fazem sentido depois do domínio
apontado e com imagens reais no lugar — que é justamente o que ainda falta.

## O QUE O QA NÃO COBRE

1. **O número do WhatsApp não foi validado.** `(85) 3491-9494` veio de um post do
   Instagram. Todos os 29 CTAs apontam para ele. **Se o número estiver errado, o
   site inteiro converte para lugar nenhum.** É o item de maior risco do projeto.
2. **Revisão técnica humana.** Nenhuma afirmação normativa foi ao ar sem fonte
   oficial, mas o conteúdo precisa da leitura do Helano antes do lançamento.
3. **Revisão ortográfica humana.** Não substituível por automação.
4. **Teste com usuário real.** Especialmente o formulário de orçamento e a
   ferramenta de orientação.
